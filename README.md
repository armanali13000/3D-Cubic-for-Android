# 🎮 3D Cubic for Android

A visually engaging 3D puzzle game built using Unity for Android devices. Navigate, rotate, and align colorful cubes to solve progressively challenging levels. Ideal for casual gamers who enjoy spatial challenges and minimalistic graphics.

## 📱 Platform

- Android (Unity Build)

## 🚀 Features

- 🧊 Smooth 3D cube interactions
- 🎯 Puzzle-based level design
- 🕹️ Touch controls for easy gameplay
- 🔄 Rotatable camera views
- 📦 Lightweight APK build (optimized for Android)
- 🎮 Unity IL2CPP build for performance
